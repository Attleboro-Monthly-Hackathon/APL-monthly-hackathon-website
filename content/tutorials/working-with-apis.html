An API is a way for your webpage to ask another service for data — weather, library catalogs, open datasets, and more.

A tiny example

Many public APIs return JSON. In the browser you can request it with fetch: 

const response = await fetch("https://api.example.com/data");
const data = await response.json();
document.querySelector("#output").textContent = data.message;

Good beginner APIs

  • Open-Meteo for weather (no key required)
  • Open Library for book metadata
  • Local open data portals for civic datasets

Tips for the library Wi‑Fi

  • Prefer APIs that do not require secret keys in frontend code.
  • Handle errors kindly — show a friendly message if the request fails.
  • Ask an organizer before calling rate-limited services in a loop.

Git remembers versions of your files so you can experiment safely. You do not need every feature today — just these basics.

Initialize a project

In your project folder, run:

git init
git add .
git commit -m "First save"

What that means

  • init — start tracking this folder
  • add — choose which files to include in the next checkpoint
  • commit — take the snapshot with a short note

Make another checkpoint

After you change files:

git add .
git commit -m "Describe what changed"

That is enough for a hackathon afternoon. Sharing to GitHub can wait until you are ready — ask an organizer if you want a walkthrough.

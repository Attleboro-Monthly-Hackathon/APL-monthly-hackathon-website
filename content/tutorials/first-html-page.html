1. Create a file

Open any text editor (Notepad, TextEdit, VS Code, or the library’s computers). Save a new file named hello.html.

2. Add this markup

Paste the following into your file:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Hello from Attleboro Public Library</title>
  </head>
  <body>
    <h1>Hello!</h1>
    <p>I made this at the APL Hackathon.</p>
  </body>
</html>

3. Open it in a browser

Double-click the file, or drag it into Chrome, Firefox, or Edge. You should see your heading and paragraph.

Light experience

Recreate a classic game with a small scope so everyone can finish and show something playable.

Project ideas

  1. Number guessing (high/low) — Computer picks a secret number; player gets higher/lower hints until they win. Track attempt count.
  2. Text adventure — Rooms, items, and simple verbs (go, take, look) in the terminal or a web page.
  3. Clicker / idle game — Click a button to earn points; unlock upgrades that auto-generate points over time.
  4. Rock–paper–scissors — Best-of series with a scoreboard and simple animations.

Learning goals

  • Variables, conditionals, and loops
  • Basic HTML structure and CSS styling
  • Handling button clicks and form input in JavaScript

Heavy experience

Build a 2D arcade-style clone and add at least one “stretch” feature (multiplayer, high scores, or effects).

Project ideas

  1. Pong — Two paddles, ball physics, scoring; optional local multiplayer (same keyboard).
  2. Snake — Grid movement, growing body, food spawn, game-over detection.
  3. Flappy Bird–style flyer — Gravity, jump on keypress, scrolling obstacles, score.
  4. Breakout / brick breaker — Paddle, ball, brick grid, lives, and level progression.
  5. Stretch features — Local multiplayer, high-score table (localStorage or a tiny backend), particle effects, sound effects.

Learning goals

  • Game loop (requestAnimationFrame or framework tick)
  • Collision detection and simple physics
  • Canvas or sprite rendering
  • State (menu → playing → game over)

Suggested session flow

  1. Pick light or heavy track and one concrete game.
  2. Sketch rules on paper (win/lose conditions, controls).
  3. Implement a minimal playable loop first; polish and stretch features last.
  4. Demo: 60 seconds of play + one thing you learned.

Theme: The power of scripts

Light experience

Write a short script that does one repetitive job reliably. Prefer local files or one free API over complex infrastructure.

Project ideas

  1. Bulk file rename — Rename a messy photo folder with dates, counters, or a consistent pattern (vacation_001.jpg).
  2. Downloads folder sorter — Move files into Images/, PDFs/, Videos/ by extension.
  3. Daily weather text / email — Call a weather API once a day and send a short summary (SMS via Twilio trial, or email via SMTP).
  4. Clipboard / note helper — Append timestamped notes to a daily log file from the command line.
  5. Duplicate finder — List or quarantine duplicate files by size + hash.

Learning goals

  • Reading command-line arguments and paths
  • Working with files and folders safely (dry-run mode first!)
  • Calling a simple HTTP API and parsing JSON

Heavy experience

Build an automation that watches something in the real world and notifies you—or that classifies and organizes content with a bit of ML or smarter rules.

Project ideas

  1. Library book availability bot — Scrape or poll the catalog for a hold/wishlist title; notify via Discord when it’s available again.
  2. Smart downloads sorter — Use filename/extension rules plus optional text classification (or keyword ML) to file documents into topic folders.
  3. Price / product watcher — Check a public product page on a schedule; alert when price drops below a threshold.
  4. Inbox / RSS digester — Fetch RSS feeds, summarize new items, post a daily digest to Discord or email.
  5. Backup & report — Zip important folders nightly and write a short status report (size, file count, last run).

Learning goals

  • Scheduling (cron, Task Scheduler, or a simple loop)
  • Parsing HTML carefully (respect robots.txt; prefer official APIs when they exist)
  • Webhooks and bot tokens (Discord)
  • Basic classification or rule engines

Safety & etiquette

  • Prefer official APIs over scraping when available.
  • Rate-limit requests; don’t hammer library or store websites.
  • Never commit API keys or Discord tokens—use environment variables.
  • Start every file script with a dry-run that only prints what it would do.

Suggested session flow

  1. Pick one annoying personal task.
  2. Automate the happy path only; handle errors second.
  3. Add a dry-run or --help flag.
  4. Demo: before/after of the messy folder or the notification popping up.
